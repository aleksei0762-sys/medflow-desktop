# MedFlow CRM — настольная программа (Windows)

Это тонкая оболочка на **Tauri**: обычная программа Windows с иконкой и отдельным
окном, которая внутри показывает рабочий экран CRM
`https://leclinic-ryazan.ru/crm/`.

Оболочка **ничего не хранит и не считает сама** — она только показывает страницу
`/crm/` вашего сайта. Поэтому сервер (WordPress с плагином MedFlow) должен быть
включён и доступен по сети. Логин — тот же, что и в браузере (сессия
WordPress хранится внутри окна программы).

Итоговый установщик получается лёгким (несколько МБ), потому что Tauri использует
системный компонент **WebView2** (он есть во всех актуальных Windows 10/11).

---

## Что нужно один раз установить на компьютере, где вы СОБИРАЕТЕ программу

Собирать `.exe`/`.msi` нужно **на Windows** (кросс-сборку под Windows с других
систем не делаем — так надёжнее). На машине сборки поставьте:

1. **Rust** — https://www.rust-lang.org/tools/install (скачать `rustup-init.exe`, запустить, согласиться с настройками по умолчанию).
2. **Microsoft C++ Build Tools** — https://visualstudio.microsoft.com/visual-cpp-build-tools/
   При установке отметьте компонент **«Разработка классических приложений на C++»** (Desktop development with C++).
3. **Node.js LTS** — https://nodejs.org/ (нужен только чтобы запустить сборщик Tauri).
4. **WebView2 Runtime** — обычно уже стоит в Windows 11 и обновлённой Windows 10.
   Если нет: https://developer.microsoft.com/microsoft-edge/webview2/ («Evergreen Standalone Installer»).

> Проверить, что Rust встал: откройте «Командную строку» и выполните `rustc --version`.

## Сборка установщика (по шагам)

Откройте «Командную строку» (cmd) или PowerShell в папке проекта и выполните:

```
npm install
npm run build
```

Первая сборка идёт дольше (Rust компилирует зависимости). После неё готовые файлы
появятся здесь:

```
src-tauri\target\release\bundle\msi\MedFlow CRM_0.8.7_x64_ru-RU.msi
src-tauri\target\release\bundle\nsis\MedFlow CRM_0.8.7_x64-setup.exe
```

Любой из этих двух файлов — и есть установщик, который вы отдаёте администратору.
`.msi` удобнее для «тихой» установки в организации, `-setup.exe` — привычный мастер
установки. Можно оставить оба.

После установки в меню «Пуск» появится «MedFlow CRM» с иконкой; запуск открывает
отдельное окно без адресной строки браузера.

## Быстрая проверка без сборки установщика

Чтобы просто посмотреть, как выглядит окно (режим разработчика):

```
npm install
npm run dev
```

## Как поменять адрес сайта

Адрес вшит в одном месте. Откройте `src-tauri/src/main.rs`, замените строку:

```rust
const CRM_URL: &str = "https://leclinic-ryazan.ru/crm/";
```

на нужный адрес и снова выполните `npm run build`.

---

## Как поменять иконку

Замените файлы в `src-tauri/icons/` (`icon.ico`, `32x32.png`, `128x128.png`,
`128x128@2x.png`) своими и пересоберите. Сейчас там фирменная иконка ЛЕ Клиники
(«ЛЕ» в оранжевом кольце на тёмно-синем фоне) — она читается на всех размерах,
включая мелкий значок на панели задач. Можно сгенерировать полный
комплект из одного PNG командой `npx @tauri-apps/cli icon путь\к\логотипу.png`.

## Частые вопросы

**Нужен ли интернет?** Да — программе нужен доступ к серверу, где стоит сайт.
Если сайт открывается только внутри сети клиники, то и программа будет работать
только там же.

**Где хранятся данные?** Все данные — на сервере (в CRM). Программа их не копирует.

**Обновления.** Когда меняется сам плагин CRM на сайте — обновлять программу
не нужно: она всегда показывает текущий `/crm/`. Пересборка программы нужна только
если поменяли адрес, иконку или название.

**Подпись кода (code signing).** Установщик не подписан цифровым сертификатом,
поэтому Windows SmartScreen при первом запуске может показать предупреждение
(«Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае»).
Чтобы предупреждение не появлялось, нужен сертификат для подписи кода — это
отдельная платная процедура, при желании подключим позже.
